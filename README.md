## Installation

    cd build
    cmake -DCMAKE_BUILD_TYPE=Release ..
    make

The rtabmap-mbari executable is created in the build/bin folder.
You can also use the premade one in the MBARI folder.

## Usage

    ./rtabmap-mbari path/to/your/euroc/format/data/folder
